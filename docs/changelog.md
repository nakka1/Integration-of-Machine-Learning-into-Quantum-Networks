# Changelog

| Version | Date | Description |
| ------- | ------------ | ------------------------------------------ |
| v1 | -- | Original monolithic notebook: channel simulator, EdgeLSTM, CS_MSELoss, quantum dataplane, and orchestrator in a single Jupyter notebook, no tests, single-batch/single-seed training, `time.perf_counter()` profiling. |
